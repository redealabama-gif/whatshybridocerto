📋 Dicas de Correção

Se uma checagem falhou, veja as ações sugeridas:

  1. Banco de dados: confirme que o backend subiu sem erro e que DATABASE_PATH aponta para um arquivo gravável.
  2. Migrations: rode npm run migrate na pasta do backend.
  3. Provedores de IA: adicione uma chave ativa na aba API Keys.
  4. Erros (24h): consulte a aba Logs para investigar.
  5. Depois clique em 🔧 Tentar Correção Automática para reativar chaves órfãs.
